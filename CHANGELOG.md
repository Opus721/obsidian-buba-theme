# Changelog

What changed in each release of the Buba theme, in plain words. The newest release is at the top.

## Next (not released yet)

- In the Buba tree of the dark theme, Buba's own fold triangle (Buba 1.4) keeps its full size and stands on the middle of the folder's name: the theme no longer redraws it smaller.

## 1.1.3

- On a phone, the bookmark window keeps "Cancel" and "Save" as plain text buttons in its corners, in line with the fields and centred on the title, as in Obsidian; "Delete" is as wide as the fields.
- On phones and tablets, text fields are tall enough for a finger.
- In the Buba tree, the arrow after a long folder name stays in place, however many files the folder holds.
